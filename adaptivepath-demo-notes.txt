AdaptivePath Biology 12.2 — Cloud demo notes

Branch: feature/biology-demo
Route: /adaptivepath
Current status: source implementation committed, NOT YET runtime-verified.
This version is an explicitly labeled offline deterministic tutoring baseline, not a live AI Agent integration.

Existing application preserved:
- Original /workbench and LeetCode/Coach endpoints remain available.
- Existing Next.js layout, CoachMarkdown, Prisma singleton, SQLite adapter and navigation are reused.
- Demo route has an isolated adaptivepath_sessions table in the same SQLite database.
- sqlite-path.ts now uses PATTERNCOACH_DATA_ROOT or .patterncoach-data below the repository by default.
- Avoid running or migrating the iris profile database; use the try development profile only.

Cloud run in GitHub Codespaces (from this feature branch):
  npm ci
  npm run db:generate
  npm run db:migrate:try
  npm run db:seed:try
  npm run dev:try
Open the forwarded port 3000 and navigate to /adaptivepath.

Current demo:
- D1-D4 diagnostic questions, G1/G2 guided questions, T1-T3 transfer questions.
- Printed pages 316, 317, 319 and 320 quoted from user-provided OpenStax excerpt.
- Choose an option AND type reasoning, then Submit.
- Learner profile button shows evidence counts, mastery and misconception signals.
- Same response-dependent navigation regardless of account: D1 weak -> D4 probe, D1 strong -> D2.
- Hints and opening textbook references are logged as assistance for the current question.
- Two distinct successful independent transfer attempts are required to label a topic Stable.
- A session is stored server-side; session identifier is retained for the current browser tab only.

Important limitations and verification needs:
- Live LLM classification, real Agent tool selection, and reuse of the existing multi-tool Coach orchestration ARE NOT integrated yet. The current tutor replies through a transparent offline rule-based service.
- CER scoring is a limited heuristic, NOT validated biological NLP grading; needs live AI with deterministic policy guards.
- Current source records contain selected exact extracts, not all paragraph-level chunks from 12.2. Fill content ingestion before describing complete textbook coverage.
- The session is accessed by opaque UUID without production authentication. This is suitable only for a trusted local or private Codespaces demo, not an openly deployed multi-user service.
- SQLite session state is stored as a JSON payload per session; concurrency and production auth are not addressed.
- Automated unit tests have been added, but not run in a Node/Prisma runtime by ChatGPT; run npm run typecheck, npm run lint, npm run test:unit and npm run build in Codespaces.
- Source excerpts are for on-screen reference only. They are not sent to an LLM. Keep OpenStax attribution and check current AI-use restrictions before any API integration.
- Tests of database migrations and local-profile isolation should be reviewed in Codespaces before using this app.

Demo stories:
A) For D1 select Yes and explain that both must be RR because the dominant allele eliminates recessive. Next is D4 probe; further misconceptions lead to guided practice after diagnostics.
B) Reset; for D1 select No and explain that RR and Rr both express round phenotype. Next is D2. Complete diagnostics well; independent transfers follow without guided practice.
Neither path should award Stable after only a single transfer. Check the Profile drawer.
